# Campus Lost and Found Management System

## Project Purpose
The Campus Lost and Found Management System helps students and campus staff report lost items, register found items, search for missing belongings, and manage item reports. The goal is to make it easier to reunite lost belongings with their owners.

## Main Features
- User account creation and login
- Reporting lost items
- Registering found items
- Searching and matching items
- Filtering item reports
- Reviewing reports and updating item status
